# 📚 Library Management System

A simple **Library Management System** built using **Python** that allows users to manage books in a library through a command-line interface (CLI). The system stores all book information in a JSON file, making data persistent even after the program is closed.

## 🚀 Features

- 📖 Add new books
- ❌ Delete books
- 🔍 Search books by title or ID
- 📚 Issue books
- 🔄 Return issued books
- 💾 Automatically stores data in `library.json`
- 🖥️ Easy-to-use command-line interface

## 🛠️ Technologies Used

- Python 3
- JSON (`library.json`) for data storage
